# Submission handoff

Target: Nebius x NVIDIA Global AI Hackathon, Personal AI Track.

The listed deadline is 30 October 2026 at 10:00 AM PDT, which is 10:30 PM IST. Recheck the [event page](https://nebiusglobalaihackathon.devpost.com/) before submitting. This checklist is preparation, not a completed entry.

## Product evidence

- [ ] Run the documented setup from a freshly extracted test build.
- [ ] Run backend tests and frontend build. Record the actual result, without invented performance claims.
- [ ] Verify persistence, practice attempts, skill approval, calendar conflict/revocation and the audit flow.
- [ ] Confirm every mock connection and fallback is labeled.
- [ ] Complete a genuine Nebius runtime call using an available NVIDIA open-source model. Save non-secret model status evidence.
- [ ] Check that the recorded model matches the one named in the project description and video.

## Public deliverables

- [ ] Publish the complete source repository with the chosen open-source license and setup guide. Confirm contributor ownership and attribution.
- [ ] Provide a working demo or downloadable test build URL that judges can actually access.
- [ ] Record VIDEO-SCRIPT.md in the real application. Keep the public YouTube video under three minutes.
- [ ] Review DEVPOST-DRAFT.md. Replace pending links and live-verification disclosure only with facts you have verified.
- [ ] Provide genuine Nebius/NVIDIA feedback after using them.
- [ ] Confirm any existing-project improvement disclosure accurately describes the project history.
- [ ] Select Personal AI and review the final entry before submission.

## Account steps for the entrant

Sign in, accept applicable terms, confirm eligibility and contribution ownership, review the open-source license, make the public links accessible, and submit from your own account. Do not share API keys in the entry, recording, repository or chat.

The [official rules](https://nebiusglobalaihackathon.devpost.com/rules) are the authoritative source. This kit does not guarantee eligibility or a prize.
