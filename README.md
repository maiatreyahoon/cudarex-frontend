# CUDAREX — AURA personal AI workspace

The integrated hackathon platform lives in [platform/](platform/). It includes React, FastAPI, SQLite, guided practice, user-controlled memory and skills, approved local calendar proposals, tests, and submission materials.

Start with [the Mac guide](platform/MAC-START-HERE.md) or [the full README](platform/README.md). From this repository folder, run:

```bash
python3 platform/scripts/start.py
```

All app account integrations are mocks. Nebius/NVIDIA live verification requires a real server-side key and model ID. See [track readiness](platform/docs/HACKATHON.md).

The original frontend files remain at the repository root. [Its original README](LEGACY-FRONTEND.md) is retained as reference.
